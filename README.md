# Numbers Trainer

A listening trainer for numbers — practice understanding spoken numbers in English (US/GB) and French.

The app reads out numbers, dates, or money amounts, and you write them down by ear (dictation) or check yourself step by step. Speech is generated by your browser's built-in speech synthesis — no extra setup needed.

## Features

- **Content types:** numbers (integers, decimals, negatives), dates, currency amounts (USD, CAD, EUR, GBP)
- **Two modes:** dictation and step-by-step
- **Settings:** number range, speech rate, pauses, repeat count, session duration
- Light and dark theme

## Getting started

```bash
npm install
npm run dev
```

Open the address Vite prints (usually http://localhost:5173).

## Build

```bash
npm run build
```

The output goes to the `dist` folder.

## Tech stack

React + TypeScript + Vite.
